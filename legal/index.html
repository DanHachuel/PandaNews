🐻 Automação Editorial com IA

PandaNews

Geração e automação de blogs de notícias com Inteligência Artificial — SaaS local para criação e operação de múltiplos blogs segmentados por tema e região.

O PandaNews é uma ferramenta local (executada na máquina do usuário via npx) de automação editorial: coleta pautas em feeds RSS configurados pelo usuário, redige notícias com modelos de linguagem de IA (LLMs) e produz imagens ilustrativas, organizando tudo em múltiplos blogs com revisão humana e agendamento automático.

⚙️ Funcionalidades

📰 Múltiplos blogs por tema e região

Gestão de blogs segmentados por tema — esporte, política, economia, tecnologia, geral — e por recorte regional (Brasil, Espanha, São Paulo, Rio de Janeiro etc.), cada um com fontes e estilo editorial próprios.

📡 Coleta via feeds RSS

Pautas coletadas automaticamente das fontes RSS configuradas pelo usuário, com filtragem por relevância (tema e região) e deduplicação de itens.

🤖 Redação com LLM multi-provedor

Geração de notícias (título, resumo e corpo) com fallback por prioridade: NVIDIA NIM → Google Gemini. O provedor que responde é registrado em cada notícia.

🎨 Imagens com IA

Imagens ilustrativas em estilo fotojornalístico geradas pela API do Google Gemini Image a partir de palavras-chave da notícia, com geração manual por prompt livre.

👁️ Revisão humana

Fluxo editorial completo: rascunho → aprovado → publicado. Toda notícia nasce em rascunho para revisão, edição manual ou regeneração antes da aprovação.

⏱️ Agendamento automático

Agendador com frequência configurável por blog, toggle global e execução imediata — com logs de execução por etapa (coleta, redação, imagem).

💾 Armazenamento local

Por padrão, 100% local em SQLite (data/pandanews.db), com opção de migração para Supabase quando o usuário fornecer credenciais.

📊 Dashboard com métricas

Métricas de geração (últimos 7 dias), notícias pendentes de revisão, status do agendador, checklist de onboarding e últimos erros registrados.

🔌 Como funciona

Pipeline de geração: coleta RSS → filtragem por relevância → redação via LLM (NVIDIA NIM → Google Gemini) → imagem via Gemini Image → rascunho → revisão humana → aprovado/publicado.
O agendador repete o ciclo para cada blog ativo conforme sua frequência configurada.

🧩 Provedores de API utilizados

🟩 NVIDIA NIM

API: inference (endpoint compatível com OpenAI)

Uso: geração de texto das notícias (provedor primário do fallback)

Chave de API fornecida pelo próprio usuário, armazenada localmente.

🔵 Google Gemini

APIs: modelo de linguagem (fallback de texto) e Gemini Image (imagens ilustrativas)

Uso: redação alternativa e geração de imagens fotojornalísticas

Chave de API fornecida pelo próprio usuário, armazenada localmente.

🟢 Supabase

API: banco gerenciado (opcional)

Uso: backend de dados alternativo, apenas se o usuário optar explicitamente e fornecer suas credenciais

Por padrão, os dados permanecem em SQLite local.
