# frontend/

UI do PandaNews (React + Vite + Tailwind), inicializada na Fase 2 do plano de implementação.

- Páginas: Dashboard, Blogs, Notícias, Imagens, Automação, Configurações, Logs
- Sidebar + topbar no padrão Leadmaster
- 7 leis de usabilidade aplicadas (Fitts, Hick, Zeigarnik, Jakob, Gradiente de Meta, von Restorff, Miller)
- Build: `npm run build` → `dist/` servido em 127.0.0.1:3030
